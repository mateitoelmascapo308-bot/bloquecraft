# Bloquecraft

Un pequeño juego de supervivencia de bloques que funciona en el navegador.

## Cómo jugar

Abre `index.html` en un navegador con conexión a internet. El juego carga Three.js desde una CDN.

- **WASD**, **ZQSD** o flechas: moverse
- **Espacio**: saltar
- **Ratón**: mirar
- **Clic izquierdo / derecho**: romper / colocar bloques
- **1–5**: elegir bloque
- **V**: alternar primera y tercera persona
- **Esc**: liberar el ratón

El mundo genera terreno por chunks de 16 × 16 bloques y tiene una capa de bedrock en Y = −32.
